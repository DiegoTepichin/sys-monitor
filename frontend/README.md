# Sys-Monitor — Dashboard

React 19 + Vite + Tailwind CSS dashboard for Sys-Monitor. See the [root README](../README.md)
for architecture and setup.

```sh
npm ci           # install dependencies
npm run dev      # dev server on :3000, proxies /api → http://127.0.0.1:5002
npm run build    # production bundle in dist/ (served by Flask in Docker)
npm run lint     # oxlint
```
